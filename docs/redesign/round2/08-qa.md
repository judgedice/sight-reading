# Round 2: design QA

Every screen was captured in Chromium (dev server, fake microphone) at 1440 x 900 and 390 x 844, light and dark, into `docs/screenshots/round2/<name>-<desktop|phone>-<light|dark>.png` (126 files), and looked at beside `mockups/png/`. The walk was a Baritone voice in the built-in speakers state, not calibrated. The app opens at difficulty 2 and the walk ended at difficulty 10, so the music, key and header lines differ from the boards (difficulty 1, F major) on the later screens; those differences are state, not styling. Layout, spacing, type and colour were compared, not the music.

No CSS was changed: nothing found was a styling fault. Gaps are listed below for their owners.

Checks: `pnpm exec vitest run src/ui/tokens.contrast.test.ts` passes (205). `e2e/design/grayscale.spec.ts` passes in all 6 projects.

Mockups: `docs/redesign/mockups/_build/round2.mjs` could not read `AFTER_REFERENCE_SEC` (removed from the code), so it stopped. It now reads the one-beat gap from `firstClickAt = ref.end + 60 / plan.bpm` in `practice-session.ts` and stops if that line goes. Rebuilt and re-rendered the frames board: card 0 s, key chord 0.6 s, first note 2.3 s, first note ends 3.3 s, count-in click 4.3 s (the other boards are unchanged). `04-design.md` still quotes the older numbers (0.1 s, 1.8 s, 3.3 s, 11.3 s); its owner should update it.
